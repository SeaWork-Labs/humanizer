# 去AI味

Remove AI writing patterns from text

## 安装

从 GitHub 装（需要本机有 `git`）：

```bash
npx skills add SeaWork-Labs/humanizer#v2.1.7 --skill humanizer
```

从市场索引装（纯 HTTPS，国内网络可达）：

```bash
npx skills add https://skills.seaharness.cn --skill humanizer
```

## 内容

技能正文在 `skills/humanizer/payload/`。这些文件由转换器从市场归档逐字节搬来，改动请直接改 `skills/humanizer/payload/`，不要反向同步。版本以 git tag 为准。
